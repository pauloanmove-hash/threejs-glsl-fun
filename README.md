# Three.js + GLSL Fun

Interactive cosmic noise blob demo combining Three.js and custom GLSL shaders.

## Features
- Procedural 3D simplex noise displacement in the vertex shader
- Fresnel-based glowing colors that shift over time in the fragment shader
- Orbit controls with auto-rotate
- Smooth, high-poly icosahedron geometry

## Run locally
Just open `index.html` in a modern browser (or serve with any static server).

Uses Three.js r160 via CDN.
